# Brand and intellectual-property clearance

Review date: September 22, 2026

## Release status: TripRabbit selected; final clearance recommended

The publisher selected **TripRabbit** on September 22, 2026, replacing the
former **RoadLog** name before the first Google Play upload. The engineering
rename uses **TripRabbit** in-app and **TripRabbit: Odometer Log** in the store
listing so the current manual odometer functionality is not misrepresented as
automatic GPS trip tracking.

The preliminary exact-name search found no TripRabbit app in Google Play or
Apple's App Store, no obvious indexed U.S. trademark result, and no established
vehicle-software product using the exact name. It did find an unrelated
TripAdvisor/Linktree username and adjacent names such as TourRabbit and
FleetRabbit. Search indexes are incomplete and trademark rights can exist
without federal registration, so this is a risk screen rather than a legal
opinion or guarantee of availability. Professional clearance remains prudent
before commercial distribution.

## Why RoadLog was retired

The initial search found:

- an active iOS mileage-tracking product titled **Auto Mileage Tracker -
  RoadLog**, using `roadlog.app` and offering substantially related vehicle and
  mileage software;
- U.S. registration number 4,293,286 / serial number 85/504,167 for a stylized
  **ROADLOG** mark owned at registration by Continental Automotive GmbH,
  covering vehicle-driver recording and related fleet software in Class 9; and
- another active open-source vehicle-management product using **Roadlog**.

These overlapping names and product areas create confusion and complaint risk
even if a detailed legal analysis ultimately finds coexistence possible.

## Decision record

The rename path was chosen. TripRabbit must now be used consistently across the
app label, UI, package identity, privacy policy, store listing, screenshots,
backup branding, tests, and release documentation. Do not reintroduce RoadLog
as a primary mark or solve the old conflict merely with capitalization, spacing,
icon colour, or generic suffixes.

## Rename checklist

If a new name is selected, update and verify all of the following together:

- app label, launcher artwork, visible UI, screenshots, listing title and copy;
- privacy-policy HTML, Markdown, and in-app text;
- documentation and repository presentation;
- application ID/namespace **before the first Play upload**, if a matching
  publisher-controlled identifier is desired; an existing Play application ID
  cannot be changed in place;
- public privacy-policy URL and support contact identity;
- Play Console declarations and export-compliance record; and
- tests, filenames, backup format branding, and reviewer instructions.

Do not change the application ID casually after a release exists; that creates
a separate app rather than an update.

## Earlier replacement screen

The following exact names produced no obvious matching app-store, general-web,
or indexed USPTO result in a preliminary search on September 22, 2026. This is
only an early collision screen: search indexes are incomplete, trademark rights
can exist without federal registration, and none of these names is legally
cleared yet.

| Candidate | Positioning | Caveat |
| --- | --- | --- |
| **OdoLedger** | Directly conveys a durable odometer record | Somewhat descriptive; "odo" may be less obvious to casual users |
| **Milefolio** | Distinctive portfolio/history idea | "Mile" can sound less inclusive of kilometre users |
| **GaugeNest** | Broad, brandable home for vehicle records | Less explicit about odometer history |

**OdoLedger** is the recommended product fit of this initial set. Before
adopting any candidate, repeat exact and similar-sounding searches, check
relevant domains/social identifiers, search intended non-U.S. markets, and get
professional clearance if the app will be commercially distributed.

TripRabbit was subsequently proposed and selected after the additional exact-
name screen described above.

Rejected during the same screen: **OdoKeep** is already an active vehicle
logbook product with iOS distribution, Android plans, and claimed trademark
rights. Do not use it.
